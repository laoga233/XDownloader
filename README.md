# XDownloader

一款由 Codex 协助开发的 X/推特多媒体下载器

> v0.12.1 为内部测试版，下载完整性、兼容性和使用体验仍在验证中。

> 请确保在Windows系统，安装Chrome并拥有.NET Framework 4.7.2或以上时使用本软件

## 主要功能

- 下载指定用户公开帖子的图片和视频
- 支持按发布日期筛选
- 自动识别已下载内容，避免重复保存
- 集中保存下载记录，并支持按需导出任务信息
- 自动导入旧版记录；旧 JSON 保留在原位置

## 隐私与使用说明

> 登录通过本机专用 Chrome 窗口完成。程序不会主动收集或上传 Cookie；Chrome 会在本机保存登录会话。

导出的任务记录可能包含帖子正文和本机文件路径；诊断日志也可能包含用户名、帖子编号或链接。分享前请先检查并移除个人信息。

本项目与 X Corp. 无隶属关系，不会绕过会员或登录权限、地区限制、版权保护或平台限制。请遵守当地法律及 X 的使用规则。

## 反馈问题

如您在使用过程中遇到问题，请尽量提供以下信息：

- **程序版本**
- **系统环境：** Windows版本、Chrome版本
- **诊断日志：** 使用程序上的“导出任务记录”功能，点击后找到本次任务保存路劲的`_记录` 文件夹中的 `运行记录_*.诊断.txt`并附上
- **程序UI截图：** 方便校验下载任务设置

分享日志前请先检查其中是否包含用户名、帖子编号或链接，并按需打码。请勿提交账号密码、Cookie、ChromeProfile 文件夹或未检查过的任务导出文件。
